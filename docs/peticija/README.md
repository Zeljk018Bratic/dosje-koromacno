Politika privatnosti za peticiju "STOP KOdeCO NET ZERO"

Ova politika privatnosti objašnjava kako se obrađuju osobni podaci potpisnika ove peticije.

Autor peticije odabrao je Peticijeonline.com za automatsko generiranje ove politike privatnosti na temelju odabira napravljenih tijekom izrade peticije. Kao voditelj obrade, autor je odlučio:

    Koliko dugo se čuva

Trajanje zadržavanja podataka

Osobni podaci potpisnika čuvaju se do 31 Dec 2026, nakon čega se brišu. Autor ove peticije obvezao se prema ugovoru o obradi podataka provoditi godišnji pregled kako bi utvrdio postoji li još uvijek pravna osnova za nastavak obrade osobnih podataka potpisnika.

Politika privatnosti (GitHub Pages):

Željko Bratić / dosje-koromacno/peticija/ :

Ova web stranica (unutar repozitorija dosje-koromacno) služi isključivo kao statična informativna kopija peticije.

Nema prikupljanja podataka: Ova stranica ne koristi baze podataka, ne pohranjuje IP adrese, niti koristi kolačiće (cookies) za praćenje potpisnika.

Vanjski linkovi: Svi osobni podaci (ime, prezime, lokacija) prikupljaju se isključivo klikom na vanjski link koji vodi na platformu Peticijeonline.com. Način obrade tih podataka definiran je isključivo njihovom politikom privatnosti (navedenom iznad).

Printanje (PDF): Verzija za ispis (peticija-print.html) služi isključivo za lokalno printanje i fizičko potpisivanje. Nikakvi podaci upisani na papir ne šalju se putem ove web stranice.

Za sva pitanja vezana uz podatke na ovoj GitHub stranici, možete kontaktirati voditelja projekta na: dosje.koromacno@proton.me ili [REDACTED PERSONAL EMAIL] .
