## 4. SHA-256 — GENERIRANJE

### 4.1. Linux/Mac/Git Bash

```bash
# U root folderu repo-a
find docs/ -type f \( -name "*.md" -o -name "*.pdf" -o -name "*.docx" -o -name "*.xlsx" -o -name "*.csv" -o -name "*.html" -o -name "*.mp4" \) -print0 | sort -z | xargs -0 sha256sum > SHA256SUMS.txt
```

### 4.2. Windows PowerShell

```powershell
Get-ChildItem -Path docs -Recurse -File | Where-Object { $_.Extension -in '.md','.pdf','.docx','.xlsx','.csv','.html','.mp4' } | Sort-Object FullName | ForEach-Object { $hash = (Get-FileHash $_.FullName -Algorithm SHA256).Hash.ToLower(); "$hash  $($_.FullName)" } | Out-File -Encoding UTF8 SHA256SUMS.txt
```

### 4.3. Verifikacija

```bash
sha256sum -c SHA256SUMS.txt
```

Ako sve piše `OK` — dobro je.
